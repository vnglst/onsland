What is OnsLand?

OnsLand is an interactive visualization project that explores how land is used across European countries. Using data from Eurostat, it presents land use patterns through beautiful hexagon-based visualizations, making complex agricultural and environmental data accessible and engaging.

How to Contribute

OnsLand is an open-source project, and we welcome contributions! Here's how you can help:

  • Report bugs: Found an issue? Report it on GitHub
  • Suggest features: Have an idea for improvement? We'd love to hear it
  • Add translations: Help translate the interface to more languages
  • Update data: Help keep the visualizations current with latest Eurostat data
  • Contribute code: Submit pull requests to improve the codebase

GitHub repository: github.com/vnglst/onsland
